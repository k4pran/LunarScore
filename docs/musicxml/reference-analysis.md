# Reference importer analysis

Audited 2026-10-15 for [MX-00 / issue #1](https://github.com/k4pran/LunarScore/issues/1). This is a source audit, not a runtime comparison or parser implementation. **Verified** means inspected at the cited revision; **inference** means predicted from source; **proposal** means a LunarScore policy still to implement. No music21 code or third-party fixtures are copied into the library.

## Concrete specification / importer disagreement

**Verified entry-point limitation:** MusicXML 4.0 defines [`score-timewise`](https://www.w3.org/2021/06/musicxml40/musicxml-reference/elements/score-timewise/), with measures containing parts. Both pinned music21 entry points reject it solely because of its root. Independent F12 input:

```xml
<score-timewise version="4.0">
  <part-list><score-part id="P1"><part-name>Audit</part-name></score-part></part-list>
  <measure number="1">
    <part id="P1">
      <attributes><divisions>1</divisions></attributes>
      <note><pitch><step>C</step><octave>4</octave></pitch><duration>1</duration><type>quarter</type></note>
    </part>
  </measure>
</score-timewise>
```

Independent expectation: P1 / measure 1 / C4 at onset 0, duration 1 quarter. This example and its equivalent partwise wrapper were validated against the pinned XSD with local imports. The music21 rejection is established by its root guards, not a runtime test. MX-10 must produce equal semantic projections for both roots. Until supported, the proposed outcome is fatal `UnsupportedRoot` with root location, never an empty successful score; see the [diagnostic ledger](risks-and-gaps.md#mx-00-audit-findings-and-diagnostic-obligations).

Validation evidence (2026-10-15, Windows): .NET `XmlSchemaSet` preloaded the pinned `xml.xsd`, `xlink.xsd` and `musicxml.xsd`; `XmlResolver = null`, reader `DtdProcessing = Prohibit`. Both wrappers passed schema validation. Schema inputs are identified by the [inventory checksums](element-inventory.md#reproducible-source-pin). This validates the counterexample's structure, not an importer or any platform target.

The [chord definition](https://www.w3.org/2021/06/musicxml40/musicxml-reference/elements/chord/) also constrains F06: a chord tone can be shorter than the preceding reference note, cannot be longer, and does not advance the cursor. Plans saying “different durations” must include that constraint.
